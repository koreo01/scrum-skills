# V-2 (根拠なき確認質問) Few-shot例

このパターンは誤検出が多いため、confidence:high のみ通知する。

---

## Few-shot 1: 健全例（指摘対象外・判断+根拠あり）

### Input

```
パターンID: V-2
発言者: メンバーB
タイムスタンプ: 00:03:48
該当発言: "属性が変わると評価項目と評価基準が自動で変わる仕様にしたいという認識を確認"
文脈サマリ: 自分の認識を明示した上で確認質問。健全な質問パターン
会議: プロダクトバックログ・リファインメント 4/21
判定根拠: 「〇〇という認識でいる」を明示し、その認識の正誤を確認している。判断+根拠あり
```

### Output

```json
{
  "pattern_id": "V-2",
  "speaker": "メンバーB",
  "timestamp": "00:03:48",
  "trigger_summary": "『〇〇という認識』を明示した健全な確認質問",
  
  "_judgment": "HEALTHY_EXAMPLE",
  "_judgment_note": "自分の認識を明示してから確認している。これはV-2の指摘対象ではなく、むしろ良い質問の模範例として記録。",
  
  "layer1_analysis": null,
  "layer2_questions": null
}
```

## Few-shot 2: 指摘対象例（confidence:high 限定・DM通知のみ）

### Input

```
パターンID: V-2
発言者: (仮想例)
タイムスタンプ: 00:00:00
該当発言: "これでいいんでしょうか?"
文脈サマリ: 自分の判断・根拠を一切示さず、判断を相手に投げている
判定根拠: 自分の判断・根拠・前提が一切示されていない、丸投げ質問
```

{
  "pattern_id": "V-2",
  "speaker": "(仮想例)",

---

## このパターンの運用方針

- **DM通知のみ**（Slackチャンネルへの自動投稿はしない）
- **confidence:high のみ通知**（誤検出を避けるため）
- **日次サマリでは末尾の傾向欄でのみ集計表示**（個別の指摘ではなく傾向データとして）
- **頻発する発言者がいる場合のみ、サマリで集計表示**
