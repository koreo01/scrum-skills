# 出力フォーマット仕様

## 個別検出の構造（Responder出力）

```json
{
  "pattern_id": "V-1",
  "speaker": "発言者氏名",
  "timestamp": "00:23:45",
  "trigger_summary": "該当発言の要約 (60字以内)",
  
  "layer1_analysis": {
    "logical_issue": "発言の論理的問題の特定 (1〜2文)",
    "theoretical_basis": "学問的・原理的根拠 (2〜3文)",
    "structured_problem": "構造化された問題整理 (任意)",
    "questions_for_sm": [
      "問い1",
      "問い2",
      "問い3"
    ],
    "implication": "答えられない場合の含意 (任意)"
  },
  
  "layer2_questions": {
    "intro": "メンバーに切り出す時の柔らかい一言",
    "questions": [
      "問い1 (柔らかいトーン)",
      "問い2",
      "問い3"
    ],
    "usage_timing": "使用想定タイミング"
  },
  
  "_meeting": {
    "title": "会議名",
    "date": "YYYY-MM-DD",
    "source": "議事録ファイル名"
  }
}
```

健全例の場合：

```json
{
  "pattern_id": "V-1",
  "_judgment": "HEALTHY_EXAMPLE",
  "_judgment_note": "...",
  "layer1_analysis": null,
  "layer2_questions": null
}
```

## 表示レベル「簡易版」の定義（確定仕様）

ユーザー確定: 簡易版を使用。具体的には：

- **layer1_analysis**: 200〜400字程度（フル版だと500〜800字）
- **structured_problem**: 該当時のみ表示（フル版は常時表示）
- **implication**: 該当時のみ表示
- **questions_for_sm**: 3問固定
- **layer2_questions.questions**: 3問固定

## 発言者名の扱い（確定仕様）

ユーザー確定: 個別の発言者名を含める。

ただし、Slack DM 配信時の文中では：
- **発言者名**: フルネーム（Gemini が議事録で識別したまま）
- **匿名化**: 行わない（あなただけが見るDMのため）

## 配信時刻

- デフォルト: **19:00 JST**
- パラメタ化済み: `config.yaml` の `delivery.daily_time` で変更可能

## 配信先

- **DM** のみ（あなた / SM のみ）
- 専用チャンネル経由は使わない

## 通知頻度の制御

- **1日あたり最大件数**: `config.yaml` の `notification.max_items_per_day` (デフォルト10件)
- **1議事録あたり最大件数**: `config.yaml` の `safety.max_detections_per_meeting` (デフォルト5件)
- **同一発言者・同一パターン上限**: `safety.max_per_person_per_pattern_per_day` (デフォルト2件)

これらを超えると、Tierの高い順に上限まで表示し、残りは「他N件」と件数のみ表示される。
