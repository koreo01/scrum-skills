# Development Team Agents

## Status: 📋 Planned

このディレクトリには開発チームの各専門エージェントを配置します。

## 予定されるエージェント

### Architect Agent (`architect/CLAUDE.md`)
- システム設計、技術選定
- 非機能要件の担保
- ADR作成

### Full-Stack Developer Agent (`fullstack/CLAUDE.md`)
- 機能実装、コードレビュー
- リファクタリング
- 技術ドキュメント

### QA Engineer Agent (`qa/CLAUDE.md`)
- テスト戦略、テスト設計
- テストコード実装
- 品質レポート

### UI/UX Designer Agent (`uiux/CLAUDE.md`)
- ユーザー体験設計
- ワイヤーフレーム、モックアップ
- デザインシステム

---

*各エージェントは個別のサブディレクトリで実装予定*
