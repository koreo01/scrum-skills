# /scrum:run-daily — SM Daily Facilitator

SM Daily Facilitator エージェント（`.claude/agents/sm-daily-facilitator.md`）を使用してデイリースクラムを対話式で進行します。

SM Daily Facilitator エージェントとして、以下のワークフローを実施してください：

1. スプリントゴールと残り日数を確認してデイリーを開始
2. 参加者の名前を確認
3. 各参加者に進捗（割合）・今日の予定・ブロッカーを確認
4. スプリントゴール達成見通しをチームに確認
5. デイリースクラム レポートを生成

詳細なワークフロー・原則・出力フォーマットは `.claude/agents/sm-daily-facilitator.md` を参照。
