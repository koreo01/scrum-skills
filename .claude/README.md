# Project-Local Claude Skills

このディレクトリには、本プロジェクト専用のClaude Codeスキルを配置します。

## 📁 構成

```
.claude/
├── README.md              # このファイル
├── settings.json          # プロジェクト固有設定（必要に応じて）
└── skills/
    └── virtual-scrum-team/  # 仮想スクラムチーム
        ├── SKILL.md         # スキル定義（トリガー条件）
        ├── agents/          # 各エージェントのプロンプト
        ├── templates/       # 出力テンプレート
        ├── samples/         # テスト用サンプル
        └── docs/            # ドキュメント
```

## 🔄 グローバルスキルとの関係

| スコープ | パス | 用途 |
|----------|------|------|
| グローバル | `~/.claude/skills/` | 全案件共通の汎用スキル |
| ローカル | `./.claude/skills/` | 本プロジェクト専用スキル |

**優先順位**: ローカル > グローバル（同名スキルはローカルが優先）

## 🚀 使い方

プロジェクトルートでClaude Codeを起動すると、自動的にこのディレクトリのスキルが読み込まれます。

```bash
cd /path/to/this/project
claude
```

## ⚠️ 注意事項

- このディレクトリには案件固有の情報が含まれる可能性があります
- `.gitignore`での除外や、適切なアクセス制御を検討してください
